# Tic Tac Toe

A simple command-line Tic Tac Toe game written in Python.  
The game is for two players and was created to practice basic Python programming concepts.

## Installation

1. Open a terminal.
2. Go to the directory where you want to save the project.
3. Clone the repository:

```bash
git clone https://github.com/floreencia/tic-tac-toe
```

4. Go into the project folder:

```bash
cd tic-tac-toe
```

## How to Play

Run the game with:

```bash
python3 tic-tac-toe.py
```

Follow the instructions in the terminal and take turns placing X and O.
